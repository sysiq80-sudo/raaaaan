

## خطة نقل المشروع بالكامل إلى مشروع جديد

### ما سيتم تحقيقه
نسخ كاملة من الكود مع قاعدة بيانات نظيفة جديدة ورابط جديد، بدون أي تأثير على المشروع الحالي.

---

### الخطوات المطلوبة

#### 1. إنشاء نسخة من المشروع (Remix)
- اذهب إلى **إعدادات المشروع** (Settings)
- اضغط على **"Remix this project"**
- سيتم إنشاء مشروع جديد بنفس الكود مع رابط جديد تلقائياً

#### 2. إنشاء مشروع Supabase جديد
- اذهب إلى [Supabase Dashboard](https://supabase.com/dashboard)
- أنشئ مشروع جديد بقاعدة بيانات فارغة
- احتفظ بـ Project URL و Anon Key الجديدة

#### 3. ربط المشروع الجديد بـ Supabase الجديد
في المشروع المنسوخ (Remix):
- اذهب إلى Settings → Supabase
- اختر "Connect to different Supabase project"
- أدخل بيانات المشروع الجديد

#### 4. تطبيق هيكل قاعدة البيانات
نفّذ migrations الموجودة في المشروع على قاعدة البيانات الجديدة:
- افتح SQL Editor في Supabase Dashboard الجديد
- طبّق ملفات الـ migrations بالترتيب من مجلد `supabase/migrations/`

---

### النتيجة
- مشروع جديد برابط مختلف (مثل: `new-project-name.lovable.app`)
- قاعدة بيانات Supabase جديدة فارغة بنفس الهيكل
- المشروع الأصلي يبقى كما هو بدون أي تغيير

---

### ملاحظات تقنية
- يجب تحديث Edge Functions secrets في المشروع الجديد
- إذا كنت تستخدم Google Maps API أو خدمات أخرى، تأكد من تحديث المفاتيح
- الـ migrations ستحتاج تطبيقها يدوياً على قاعدة البيانات الجديدة
