# نظام التنبيهات الذكية للسائق - Driver Smart Alerts

## 📋 نظرة عامة

نظام تنبيهات ذكي يظهر بجانب أيقونة الجرس في الهيدر الخاص بالسائق. يعرض التنبيهات المهمة ويسمح للسائق بالتفاعل معها مباشرة.

---

## 🎯 الموقع

- **الصفحة**: `src/pages/driver/DriverHome.tsx`
- **المكون**: `src/components/driver/DriverAlerts.tsx`
- **الموضع**: في الهيدر العلوي، جانب الجرس (يسار)

---

## 🔔 أنواع التنبيهات

### 1. **في انتظار الموافقة** ⚠️

- **الشرط**: `!adminActivated || driverStatus === 'pending'`
- **النوع**: تحذير (warning)
- **الرسالة**: "حسابك قيد المراجعة من قبل الإدارة. سيتم تفعيلك قريباً."
- **الإجراء**: الانتقال إلى `/driver/status`
- **الأيقونة**: ShieldAlert (برتقالي)

### 2. **أكمل بياناتك** 📄

- **الشرط**: `!isProfileComplete`
- **النوع**: تحذير (warning)
- **الرسالة**: "لم تكمل جميع البيانات المطلوبة. أكمل ملفك لتسريع عملية المراجعة والموافقة."
- **الإجراء**: الانتقال إلى `/driver/complete-registration`
- **الأيقونة**: FileCheck (برتقالي)

### 3. **الإشعارات مفعّلة** ✅

- **الشرط**: `notificationPermission === 'granted' && isOnline`
- **النوع**: نجاح (success)
- **الرسالة**: "ستصلك تنبيهات الطلبات الجديدة"
- **الإجراء**: الانتقال إلى `/driver/settings`
- **الأيقونة**: Bell (أخضر)

### 4. **الإشعارات معطّلة** ⚠️

- **الشرط**: `notificationPermission === 'denied' && isOnline`
- **النوع**: تحذير (warning)
- **الرسالة**: "لن تصلك تنبيهات الطلبات. قم بتفعيل الإشعارات من الإعدادات."
- **الإجراء**: الانتقال إلى `/driver/settings`
- **الأيقونة**: BellOff (برتقالي)

### 5. **فعّل الإشعارات** ℹ️

- **الشرط**: `notificationPermission === 'default' && isOnline`
- **النوع**: معلومات (info)
- **الرسالة**: "لاستقبال تنبيهات الطلبات الجديدة بشكل فوري."
- **الإجراء**: الانتقال إلى `/driver/settings`
- **الأيقونة**: Bell (أزرق)

## 🎨 التصميم

### الأيقونة الرئيسية

```tsx
- إذا كانت هناك تحذيرات: AlertCircle (برتقالي)
- إذا كانت جميع التنبيهات إيجابية: CheckCircle (أخضر)
- Badge يظهر عدد التنبيهات (برتقالي للتحذير، أخضر للنجاح)
```

### القائمة المنبثقة (Popover)

```tsx
- العرض: 320px (w-80)
- الارتفاع الأقصى: 400px للمحتوى
- التموضع: align="end" (من اليمين)
- التباعد: sideOffset={8}
```

### بطاقة التنبيه

```tsx
- خلفية hover: accent/50
- أيقونة مخصصة لكل نوع
- زر إجراء بعرض كامل
- نوع الزر: default للتحذيرات، outline للبقية
```

## 📊 المعاملات (Props)

```typescript
interface DriverAlertsProps {
  isProfileComplete: boolean; // هل الملف الشخصي مكتمل؟
  notificationPermission: NotificationPermission; // حالة أذونات الإشعارات
  isOnline: boolean; // هل السائق متصل؟
  adminActivated: boolean; // هل تمت الموافقة من المدير؟
  driverStatus: string | null; // حالة السائق (pending/approved/etc)
}
```

## 🎯 تجربة المستخدم (UX)

### السلوك

1. **النقر على الأيقونة**: فتح القائمة المنبثقة
2. **النقر على زر الإجراء**: إغلاق القائمة والانتقال للصفحة المطلوبة
3. **لا تنبيهات**: المكون لا يظهر (`return null`)

### الأولوية

التنبيهات تظهر بترتيب الأهمية:

1. موافقة المدير (أعلى أولوية)
2. إكمال البيانات
3. حالة الإشعارات
