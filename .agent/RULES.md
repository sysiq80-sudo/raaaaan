# قواعد مشروع ران — RAAN Project Rules

## ⚠️ قاعدة التكلفة المالية (MANDATORY)

**قبل تنفيذ أي تعديل على الكود يمكن أن يؤثر على التكلفة المالية، يجب إخبار المستخدم والحصول على موافقته.**

### ما الذي يُعتبر تكلفة مالية؟

1. **Google Maps API**
   - إنشاء `new google.maps.Map()` — $7/1000 تحميل
   - `Geocoder.geocode()` (Reverse/Forward) — $5/1000 طلب
   - `DirectionsService.route()` — $5-10/1000 طلب
   - `Places API` (searchNearby, getDetails) — $17-32/1000 طلب
   - `Distance Matrix` — $5-10/1000 طلب
   - ⚡ **ملاحظة**: تحميل سكربت Google Maps (`loadGoogleMaps`) مجاني — التكلفة فقط عند استخدام الخدمات

2. **Supabase**
   - زيادة عدد الطلبات (queries) بشكل ملحوظ
   - إضافة Realtime subscriptions جديدة
   - استدعاء Edge Functions إضافية
   - زيادة حجم التخزين (Storage)

3. **خدمات خارجية أخرى**
   - أي API خارجي جديد (SMS, Email, AI, إلخ)
   - Firebase / FCM
   - Sentry (حجم الأحداث)
   - أي CDN أو خدمة استضافة

4. **البنية التحتية**
   - إضافة dependencies كبيرة تزيد حجم البناء
   - تغييرات تزيد استهلاك الباندويث بشكل كبير

### كيفية الإبلاغ

عند اكتشاف أن تعديلاً قد يزيد التكلفة:

```
⚠️ تنبيه تكلفة مالية:
- العملية: [وصف العملية]
- الخدمة: [Google Maps / Supabase / إلخ]
- التكلفة التقديرية: [مثال: $5 لكل 1000 طلب]
- التأثير المتوقع: [مثال: يُضيف ~500 طلب يومياً]
- هل تريد المتابعة؟
```

### استثناءات (لا تحتاج إبلاغ)

- تحميل سكربتات JavaScript (مجاني)
- Pre-loading / lazy-loading للمكونات
- تعديلات CSS / UI
- تحسينات أداء لا تزيد عدد الطلبات
- استخدام Cache لتقليل الطلبات (هذا يوفر المال)
- قراءة من localStorage / sessionStorage
