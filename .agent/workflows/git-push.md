# قواعد Git Push

## القاعدة الأساسية
**لا ترفع التطبيق إلى GitHub (git push) إلا بأمر صريح من المستخدم.**

## ما يمكنك فعله بدون إذن:
- `git add` — إضافة الملفات للـ staging
- `git commit` — عمل commit محلي

## ما يحتاج أمر صريح من المستخدم:
- `git push` — الرفع لأي branch على GitHub
- `git push origin main` — الرفع للـ main
- `git push origin <branch>` — الرفع لأي branch

## كيف تعرف أن المستخدم يريد الرفع:
- يقول "ارفع" أو "push" أو "ادفع"
- يقول "ارفع للـ main" أو "push to main"
- يقول أي عبارة تدل صراحة على الرفع

## ملاحظة:
- يمكنك عمل commit محلياً في أي وقت
- انتظر أمر المستخدم قبل أي git push
