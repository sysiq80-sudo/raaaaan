# 📊 ملف بيانات المعالم - أربيل والأنبار

هذا الملف يحتوي على **30 معلماً رئيسياً** لمحافظتي أربيل والأنبار جاهزة للاستيراد.

---

## 📋 المحتوى

### 🏙️ أربيل (14 معلماً)

- قلعة أربيل (معلم تاريخي - UNESCO)
- مطار أربيل الدولي
- جامعة صلاح الدين
- 3 مستشفيات رئيسية
- 2 مجمع تجاري (مول)
- مساجد ومطاعم وفنادق

### 🏜️ الأنبار (16 معلماً)

- مطار الرمادي
- جامعة الأنبار
- 4 مستشفيات

- أسواق ومحطات وقود
- مباني حكومية

## 🔧 كيفية الاستخدام

### 1️⃣ فتح الملف في Excel

```bash
# افتح الملف:
data/landmarks_erbil_anbar.csv
```

### 2️⃣ الأعمدة الموجودة

- `name_ar` - الاسم العربي (إجباري)
- `name_en` - الاسم الإنجليزي
- `name_ku` - الاسم الكردي (لأربيل)
- `category` - التصنيف
- `lat` - خط العرض
- `lng` - خط الطول
- `address_ar` - العنوان بالعربية
- `phone_numbers` - أرقام الهواتف
- `properties` - خصائص إضافية (JSON)

### 3️⃣ الاستيراد من لوحة المدير

1. افتح: http://localhost:8080/admin/landmarks
2. اضغط على "استيراد من ملف"
3. اختر الملف `landmarks_erbil_anbar.csv`
4. راجع البيانات واضغط "استيراد"

### 4️⃣ أو استيراد يدوي

قم بنسخ البيانات ولصقها واحدة تلو الأخرى في نموذج "إضافة معلم جديد"
