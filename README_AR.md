# تطبيق ران للتاكسي الذكي 🚗

تطبيق تاكسي ذكي مصمم خصيصاً لمحافظة الأنبار في العراق.

## التشغيل السريع

### 1. تشغيل التطبيق محلياً

```bash
# الطريقة الأولى: استخدام ملف bat (الأسهل)
start.bat

# الطريقة الثانية: استخدام npm مباشرة
npm run dev
```

سيتم فتح التطبيق تلقائياً على: `http://localhost:5173`

### 2. بناء التطبيق للإنتاج

```bash
# استخدام ملف bat
build.bat

# أو استخدام npm
npm run build
```

## المتطلبات

- **Node.js** (الإصدار 18 أو أحدث)
- **npm** (يأتي مع Node.js)
- اتصال بالإنترنت (للمرة الأولى فقط)

## التثبيت

1. **تحميل المشروع:**

```bash
git clone <repository-url>
cd taksi-iraqi-smart-main
```

2. **تثبيت المكتبات:**

```bash
npm install
```

3. **إعداد ملف البيئة:**

   - الملف `.env` موجود بالفعل مع الإعدادات
   - لا حاجة لتعديل شيء للتطوير المحلي

4. **تشغيل التطبيق:**

```bash
npm run dev
```

## الأوامر المتاحة

| الأمر             | الوصف                        |
| ----------------- | ---------------------------- |
| `npm run dev`     | تشغيل التطبيق في وضع التطوير |
| `npm run build`   | بناء التطبيق للإنتاج         |
| `npm run preview` | معاينة البناء النهائي        |
| `npm run lint`    | فحص الكود                    |

## ملفات Batch المتاحة

| الملف       | الوصف                |
| ----------- | -------------------- |
| `start.bat` | تشغيل سريع للتطبيق   |
| `build.bat` | بناء التطبيق للإنتاج |

## البنية التقنية

- **Frontend:** React 18 + TypeScript
- **UI Framework:** shadcn/ui + Tailwind CSS
- **Backend:** Supabase (Database + Auth + Storage)
- **Maps:** Mapbox GL
- **State Management:** React Query
- **Routing:** React Router v6

## الصفحات الرئيسية

- `/` - الصفحة الرئيسية
- `/auth` - تسجيل الدخول
- `/rider` - واجهة الراكب
- `/driver` - واجهة السائق
- `/admin` - لوحة الإدارة

## المشاكل الشائعة

### المنفذ 5173 مستخدم بالفعل

```bash
# أوقف العملية الحالية أو استخدم منفذ آخر
npm run dev -- --port 3000
```

### خطأ في تثبيت المكتبات

```bash
# احذف المجلد وأعد التثبيت
rmdir /s /q node_modules
npm install
```

### التطبيق لا يفتح تلقائياً

افتح المتصفح يدوياً وانتقل إلى: `http://localhost:5173`
